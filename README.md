# memory-game

A browser-based memory card game created as part of the Rolling Scopes School course.

## Features

- 8 pairs of cards
- Card flip animation
- Moves counter
- Pairs found counter
- New Game button
- Victory modal
- Leaderboard
- Game results saved in Local Storage
- Responsive design

## Technologies

- HTML
- CSS
- JavaScript
- Local Storage

## How to play

1. Click on a card to reveal it.
2. Click on another card.
3. If the cards match, the pair remains open.
4. If they do not match, both cards are hidden again.
5. Find all 8 pairs to win.
